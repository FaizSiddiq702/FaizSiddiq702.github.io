# Faiz Siddiq — Portfolio

A monochrome, glass-inspired portfolio for solutions architecture, agentic AI, technical pre-sales, and telecom automation.

## Run locally

No dependency installation or build is required:

```sh
python3 -m http.server 4173
```

Open http://localhost:4173.

## Edit

- `index.html`: introduction, career, education, contact details, metadata.
- `script.js`: eight project case studies, skills, filters, and dialogs.
- `style.css`: responsive layout, glass effects, typography, reduced-motion support.
- `faiz-siddiq.png`: original supplied portrait, rendered in grayscale with CSS.
- `Faiz_Siddiq_Resume.pdf`: downloadable résumé.

## Hosting

Deploy the repository root from the `main` branch with GitHub Pages. Public repositories can use GitHub Pages on GitHub Free, including the provided `github.io` subdomain. No custom domain, paid libraries, APIs, database, analytics, or contact-form service is required. Free-provider policies can change; all files can be moved to another static host.

Official documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

The email link opens the visitor's mail client. The copy button uses browser clipboard access and provides a fallback message. There is no backend form or message collection.

Project statements are based on Faiz's supplied résumé. Customer projects were delivered through DvSum. Illustrations are conceptual system views, not screenshots of proprietary products. Estimates, targets, simulations, and in-progress work are labeled in the case studies.
